MADE FOR EVERYDAY USE

看得清，也控得住。

从一个温度读数，到一段有结束时间的控扇会话，每一步都有可检查的状态。

01

温度，带着来源一起读。

查看 SMC 与 IOHID 测点、状态和时间。异常数据保留为异常，不用一个看似正常的数字掩盖读取失败。

02

调速，有开始也有结束。

每次手动控扇必须指定持续时间，并检查设备支持的转速范围。会话提供目标写入、实际转速与恢复自动的回执。

03

同一个核心，两种用法。

SwiftUI 菜单栏界面与 CLI 共用采集和控制核心。Agent 可先读取 schema、capabilities 和 doctor，再决定下一步。

KNOW BEFORE YOU START

把边界，
也说清楚。

使用前了解版本、兼容范围与数据含义。
有具体问题，欢迎在 GitHub 提交反馈。

支持所有 Mac 吗？

当前面向 Apple Silicon、macOS 15+ 的构建。真实控扇只在有限机型上验收；没有风扇的 Mac 不具备控扇能力。请以 doctor、capabilities 和仓库硬件验收记录为准。

需要模型、API Key 或远程服务吗？

应用和 CLI 本身不需要模型或 API Key。coding agent 是可选的操作入口，不影响本地监测。

到期一定能恢复自动吗？

应用使用独立守护与读回，尽力在到期、中断和退出时恢复自动模式。仍需检查恢复回执；睡眠、未验收机型和实验路径不能当作已保证的行为。

系统权限如何处理？

读取通常不需要管理员权限。首次安装受限控扇 Helper 需要系统授权。开发包可能被 Gatekeeper 提示，按系统界面确认，不关闭系统安全保护。
